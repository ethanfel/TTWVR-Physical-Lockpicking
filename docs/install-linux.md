# Install on Linux

1. Download the [ready-to-play 1.1.8-r4 ZIP](https://github.com/ethanfel/TTWVR-Physical-Lockpicking/releases/download/1.1.8-r4/TTWVR-Physical-Lockpicking-1.1.8-r4-Ready-to-Play.zip).
2. In Fluorine, use **Install a mod from an archive** and select the ZIP. Enable the mod and **TTWVRLockKit.esp** in the profile you use for TTWVR 1.1.6, 1.1.7 or 1.1.8.
3. Start TTWVR with your usual headset and launcher.

If upgrading from the old installer, enable just one copy of the addon. You can remove its old OpenXR registry entry and `TTWVR_PHYSICAL_LOCKPICKING=1` launch option.
